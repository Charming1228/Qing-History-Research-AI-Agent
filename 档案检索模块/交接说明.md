# 档案检索模块 — 交接说明

## 你拿到的东西

```
档案检索模块/
├── archive_retriever.py          # 检索脚本（唯一需要 import 的文件）
├── cache/
│   ├── bm25_index.pkl            # BM25 关键词索引 + 全部 248,342 条档案原文
│   ├── faiss_index.bin           # FAISS 语义向量索引（BGE-large-zh-v1.5）
│   ├── doc_entities.pkl          # 每篇文档的实体标注（人名/机构/地名等）
│   └── metadata.json             # 索引构建时间等元信息
├── models/
│   └── bge-large-zh-v1.5/        # 本地 embedding 模型
└── 交接说明.md                    # 本文件
```

## 快速开始

确保目录结构不变（`cache/` 和 `models/` 与 `archive_retriever.py` 在同一级），然后：

```python
from archive_retriever import ArchiveRetriever

# 初始化：首次从缓存加载（秒级完成），无需原始 JSON 数据
retriever = ArchiveRetriever()
retriever.load_or_build()

# 检索
results = retriever.search("乾隆年间福建水师海防", top_k=10)
```

## 输入输出说明

**你的三库 agent 要做的事：**

```
用户问题
  ├── archive_retriever.search(问题)  → 档案检索结果列表
  ├── chronicle.search(问题)           → 编年检索结果列表（你来实现）
  └── dictionary.search(问题)          → 辞典检索结果列表（你来实现）
       │
       ▼
  合并三路结果 → 前端展示
```

**`search()` 返回的每条结果结构：**

```python
{
    "rank": 1,                         # 排名
    "final_score": 0.795,              # 综合排序分（0~1）
    "bm25_score": 12.336,              # BM25 关键词得分
    "vector_score": 0.594,             # 语义向量相似度
    "rrf_score": 0.032,               # RRF 融合得分
    "relation_score": 0.590,           # 关系加权总分
    "entity_score": 0.18,              # 实体共现得分（30%权重）
    "inst_score": 0.12,                # 机构隶属得分（30%权重）
    "temporal_score": 0.15,            # 时序邻近得分（20%权重）
    "geo_score": 0.10,                 # 地理关联得分（20%权重）
    "matched_entities": ["乾隆", "兵部", "福建"],  # 查询与文档的匹配实体
    "record": {                        # ★ 档案原文（这是你要展示的内容）
        "题名": "题为咨送福建水师提督等事",
        "内容提要": "兵部咨称福建水师提督员缺...",
        "责任者": "兵部",
        "责任时间(中历)": "乾隆56年2月",
        "来源朝代": "乾隆"
    }
}
```

核心字段是 **`record`**——它就是匹配到的档案原文记录。你前端展示档案检索结果时，展示 `record["题名"]`、`record["内容提要"]`、`record["责任者"]`、`record["责任时间(中历)"]` 即可。

## 依赖

对方机器需要安装以下 Python 包（Anaconda base 环境已自带大部分）：

```
jieba, rank-bm25, opencc, numpy, faiss-cpu, sentence-transformers
```

模型会自动从 HuggingFace 下载（如果 `models/` 目录完整则直接用本地）。

## 注意事项

- 不要删除 `cache/` 中任何文件，那是全部索引
- 如果确实需要重建索引（比如加入了新档案数据），把原始 JSON 放到 `数据基础/档案_过滤/` 目录下，然后 `ArchiveRetriever().load_or_build(force_rebuild=True)` 即可
- 档案检索无需原始 JSON 文件也能正常工作（24.8 万条记录已嵌入 BM25 缓存）
