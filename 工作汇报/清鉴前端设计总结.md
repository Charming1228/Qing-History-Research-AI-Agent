# 清鉴 · 清史研究智能体 — 前端设计总结

## 一、整体设计概念："数字御书房"

设计灵感来自**清宫御书房**——皇帝查阅典籍、批阅奏折的空间。整个页面只做了一件事：**左边聊天、右边查证**。用户和智能体对话时，每一条回答都能追溯到具体的史料出处，就像学者翻书查证一样。

---

## 二、从头到尾的每一个部分

### 1. 文档基础 (`<head>`)

| 部分 | 内容 | 作用 |
|------|------|------|
| 字符集 | `UTF-8` | 中文不乱码 |
| 视口 | `width=device-width` | 手机/电脑自适应 |
| 标题 | `清鉴 · 清史研究智能体` | 浏览器标签页名字 |
| 字体 | 从 Google Fonts 引了4种中文字体：**Noto Serif SC**(正文衬线体)、**Noto Sans SC**(无衬线体)、**Ma Shan Zheng**(书法体)、**ZCOOL XiaoWei**(小薇体) | 营造古雅的中文排版质感 |

### 2. CSS 变量系统 (`:root`)

所有颜色、尺寸、字体都用 CSS 变量定义，后期改配色只需改一处。

**三套颜色体系：**

- **宫廷主题色** — 宫墙红(`#B23A3A`)、鎏金(`#B49450`)、墨色(`#2C2416`)、宣纸色(`#F8F3E8`)、青玉色(`#5D8A6A`)等
- **三种史料专属色** — 词典用**檀木棕**(`#8B4513`)、编年用**古卷青**(`#2E5E4E`)、档案用**奏折紫**(`#7B3F5C`)
- **语义色** — 表面色、边框色、文字层级色（主要/次要/弱化）

**字体分层：**
- `--font-display`：标题用衬线体
- `--font-calligraphy`：印章/logo用书法体
- `--font-body`：正文用无衬线体

**动画缓动：**
- `--ease-spring`：弹性动画，用于弹入效果
- `--ease-smooth`：平滑过渡，用于hover等交互

### 3. 宣纸纹理背景

用 CSS 伪元素 `body::before` 模拟了三层效果：
- **横纹**：`repeating-linear-gradient` 做出一条条细线，模仿宣纸纤维
- **三个彩色光晕**：金色、红色、青色的 `radial-gradient`，分别从不同角落渗入，模仿旧纸泛色的质感

纯 CSS 实现，不吃性能。

### 4. 页面布局 (`#app`)

整体是一个**左右双栏**的 flex 布局：
- **左侧**：对话面板，`flex: 1`（占满剩余空间）
- **右侧**：引用面板，固定 420px 宽，可折叠

---

### 5. 左栏 — 对话区 (`.chat-panel`)

从上到下分为三层：

#### 5.1 顶栏 (`.chat-header`)
- **品牌标识**：一个红底白字的圆角方块，书法体"鉴"字
- **标题区**：中文名"清鉴" + 英文副标题"QING DYNASTY RESEARCH AGENT"
- **操作按钮**：一个"+"号按钮，用于新建对话

#### 5.2 消息区 (`.messages-container`)
- 可滚动，自定义了古铜色调的细滚动条
- **欢迎状态** (`.welcome-area`)：
  - 一个双层圆环的"印章"图标，中间是书法体"清"字
  - 标题："清史研究智能助手"
  - 副标题：一句话介绍融合三种文献
  - **提示词胶囊** (`.hint-chip`)：4个可点击的椭圆形按钮，分别是"雍正朝军机处"、"八旗制度演变"、"乾隆十全武功"、"江南织造局"
- **消息气泡** (`.message`)：
  - 用户气泡：右对齐，蓝色系，头像显示"U"
  - 智能体气泡：左对齐，白色背景带阴影，头像显示红底书法"清"字
  - 每条消息下有灰色时间戳
- **引用标签** (`.citation-tag`)：智能体回答中的 `[1]` `[2]` 等引用号，按史料类型分别上色（棕/青/紫），点击可跳转到右侧对应卡片
- **打字指示器** (`.typing-indicator`)：三个小圆点上下弹跳动画

#### 5.3 输入区 (`.input-area`)
- **输入框**：圆角白色卡片，带 `textarea`（支持自动增高），聚焦时边框变金色
- **发送按钮**：红色圆形按钮，hover 放大 + 阴影，点击缩小（反馈感强）
- **底部信息**：左侧"三库检索：词典 · 编年 · 档案"，右侧绿色圆点 + "清史知识库"

---

### 6. 右栏 — 引用详情区 (`.reference-panel`)

#### 6.1 顶栏
- 图标 📜 + 标题"史料引用"
- 引用计数标签（如"3 条"）
- 折叠按钮（`>`箭头）
- 折叠后右边出现一个悬浮展开按钮

#### 6.2 来源分布条 (`.source-breakdown`)
- 一条三色分段进度条，显示词典/编年/档案各占多少比例
- 下方三个标签，各带对应颜色的圆点

#### 6.3 引用卡片 (`.ref-card`) — 三种史料各有不同的展示格式

| 史料类型 | 配色 | 卡片特点 |
|----------|------|----------|
| **词典** (dictionary) | 檀木棕 | 显示标题 + 引用摘录（灰底左边框） |
| **编年** (chronicle) | 古卷青 | **双栏并排**：左边文言原文（暖黄底）、右边 LLM 精炼现代文（绿底） |
| **档案** (archive) | 奏折紫 | 显示**具奏人/呈送人**信息 + 奏折原文摘录 |

每张卡片还有：
- 类型标签（带图标和背景色）
- 相关度进度条（金色填充，显示百分比）
- 日期和来源出处
- hover 时向左偏移 + 阴影
- 激活时左侧加粗色条

#### 6.4 空状态
- 一本书的 emoji + 提示文字"此处将展示原始史料详情"

---

### 7. JavaScript 逻辑

#### 7.1 状态管理 (`state` 对象)
维护了6个状态：消息列表、引用列表、当前高亮引用、面板折叠状态、加载状态、会话 ID。

#### 7.2 API 接口层
- 唯一端点：`POST /api/chat`
- 请求体：`{ query, session_id }`
- 返回体：`{ answer, references[] }`
- 如果后端未连接，自动降级到**模拟数据**

#### 7.3 模拟数据 (`generateMockResponse`)
包含"雍正"关键词的完整演示数据，覆盖三种史料类型各一条，方便在没有后端的条件下演示完整效果。

#### 7.4 聊天流程
1. 用户发消息 → 隐藏欢迎区 → 添加用户气泡 → 清空输入框
2. 显示打字动画 → 调用 API
3. 收到回复 → 移除动画 → 添加智能体气泡 → 更新右侧引用面板
4. 自动滚动到底部

#### 7.5 消息内容处理 (`formatMessageContent`)
- `**bold**` → `<strong>`（加粗）
- 换行 → `<br>`
- `[1]` `[2]` → 自动匹配引用列表，生成带颜色的可点击引用标签

#### 7.6 引用面板逻辑
- `renderReferences()`：根据引用列表生成卡片，编年类型用双栏布局，档案类型显示具奏人
- `updateSourceBreakdown()`：统计三种类型数量，更新分布条宽度
- `highlightReference()`：点击对话中的引用标签，自动展开右侧面板并滚动到对应卡片

#### 7.7 响应式设计
- 屏幕宽度 ≤ 900px 时，右侧面板变为**浮层**覆盖在对话区上方，避免挤压

---

## 三、一句话总结

> 这个前端用"左聊右证"的双栏布局，融合清代宫廷配色和宣纸纹理，把智能体回答中的每一处引用都可视化为词典/编年/档案三种史料卡片，让用户一眼就能追溯到原始出处，实现了"对话即查证"的学术研究体验。
